## Easier for people new to Git

- The installer checks for Git for Windows and offers its download page if it's missing.
- Mission 4 (branch and merge) is now four small steps, each with its own button and tick, using your real branch name.
- "Allow changes in this folder" button right where you need it for your own projects.
- Plainer words for changes, saved versions, author details, and folders inside another project (with "Pick a different folder").
- Cancelling the "I know Git" check returns Home with a clear next step.
- Short walkthrough hides only finished missions.
- Offline upload error offers "Fix the web address" and "Finish without uploading".
- GitHub links now say "Create a free account" and "Create an empty repository"; the 3-step GitHub card shows once.
- "I've installed it, check again" re-checks Git without restarting the app.
- Keyboard hints on dialogs.
- Saved practice permission is only reused when the practice folder carries GitCompass's own marker; otherwise you're asked again.
