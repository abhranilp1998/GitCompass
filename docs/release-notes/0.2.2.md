# GitCompass 0.2.2 (beta)

## What's new

- **GitHub sign-in can work out of the box.** Release builds can now include a public GitHub App client ID (from the `GITCOMPASS_GITHUB_CLIENT_ID` repository variable). If you've saved your own client ID in **Settings → Advanced connection setup**, it still takes priority. GitCompass never ships or asks for a client secret.
- New one-time setup guide: [docs/github-app-setup.md](../github-app-setup.md).

> If the repository variable isn't set yet, this build behaves like 0.2.1. GitHub sign-in needs a client ID entered in Settings.

Requirements, checksum steps and other limitations are unchanged from [0.2.0](0.2.0.md).
