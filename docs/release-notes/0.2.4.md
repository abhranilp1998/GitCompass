# GitCompass 0.2.4 (beta)

## What's new

- **Undo last step.** After you stage files or save a version, Changed files shows an **Undo last step** card. Like everything else, the undo is previewed first.
  - *Undo staging* takes the files out of the next save. Your files aren't touched.
  - *Undo last saved version* moves your branch back one version (`git reset --soft`). Every change stays staged, so you can fix it and save again. It's only offered for an ordinary version that **hasn't been uploaded**: GitCompass checks the actual online copy and refuses if it can't be sure.
- **Plain-language help for common Git errors.** Merge conflicts, detached HEAD, rejected uploads and sign-in or permission problems now include an "In plain words" explanation and a "What to do" step, alongside the original message.

Requirements, checksum steps and known limitations are unchanged from [0.2.0](0.2.0.md) and [0.2.2](0.2.2.md).
