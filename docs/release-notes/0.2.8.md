# GitCompass 0.2.8 (beta)

## New: a real installer
- **`GitCompass-Setup-0.2.8.exe`** is now the recommended download: Next, Next, Finish.
- Installs just for you in `%LOCALAPPDATA%\Programs\GitCompass`. No administrator rights.
- Start menu shortcut, optional desktop shortcut, "Launch GitCompass" at the end, and a normal uninstaller in Windows Settings > Apps.
- The portable ZIP is still available if you'd rather not install anything.

## Heads-up
GitCompass is not code-signed yet. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.

Checksums: each download has a matching `.sha256` file.
