# GitCompass 0.2.0 (beta)

GitCompass is a Windows app that teaches Git by doing: every change is previewed before it runs, new projects open read-only, and nothing is uploaded unless you review and approve it.

## What's new

- **Guided practice project with 5 missions.** Choose **Create guided practice project** and GitCompass shows you exactly what it will set up (a new `GitCompass-Practice` folder, a local Git repository with no remote, a sample file and a practice author for that folder only) before anything is written. Then follow five missions: see a change, stage it, save a version (commit), make and merge a branch, and an optional upload step. Your progress is saved and resumes next time.
- **Skip the walkthrough with a quick quiz.** Already know Git? Press **Skip** and answer a few friendly questions. Get them right and you go straight to opening or cloning a project; miss some and GitCompass suggests the walkthrough instead. Fully themed, with a **Clone a repo** option.
- **The original sample folder is unchanged.** **Practice with a sample project** still creates plain files without Git, so you can learn how to set up Git yourself.
- **New README and developer guide**, plus `CONTRIBUTING.md`.
- **MIT licensed.**
- **Continuous integration:** every push builds and runs the domain, real-Git, adapter, desktop, workflow and terminal test programs on Windows.

## Download and run

1. Download `GitCompass-0.2.0-win-x64.zip` and `GitCompass-0.2.0-win-x64.zip.sha256`.
2. Optional, recommended: check the download in PowerShell:
   `(Get-FileHash .\GitCompass-0.2.0-win-x64.zip -Algorithm SHA256).Hash`
   It should match the first value in the `.sha256` file.
3. Extract the whole ZIP into a folder you can write to and run `GitCompass.exe`. Read `START-HERE.md` first.

## Requirements

- Windows 11 x64 (Windows 10 x64 may work but is not the tested target).
- [Git for Windows](https://git-scm.com/download/win) installed. GitCompass doesn't install it for you.
- Microsoft WebView2 Runtime for the Terminal tab (already on most Windows 11 PCs).
- .NET is included; you don't need Visual Studio or a .NET SDK.

## Known limitations

- **Unsigned build.** Windows SmartScreen may say "Windows protected your PC". Choose **More info → Run anyway** only if the checksum matches.
- **GitHub sign-in needs a GitHub App client ID.** GitHub API features (pull requests, hosted checks) need a registered GitHub App public client ID to be configured. Local Git, lessons, the graph and normal `git push`/`fetch` work without it.
- Portable ZIP only: no installer and no auto-update.
- The bundled functional manual (PDF/HTML) was written for 0.1.1. It doesn't yet cover the new walkthrough missions or the skip quiz. The README and `docs/` folder do.
