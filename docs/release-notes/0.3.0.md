# GitCompass 0.3.0 (beta)

## Easier first steps
- **No Git? We tell you first.** Before the welcome screen, GitCompass checks for Git and shows one step: "First, install Git (free, ~2 min)", with a **Download Git** button and **I've installed it, check again**.
- **One button to start practising.** In the guided practice project, press **Let GitCompass make changes here**. GitCompass remembers it for that practice folder, so you don't have to allow it again next time.
- **Plain permission messages.** The "allow changes" and "switch to a safer mode" boxes now say what happens in everyday words.

## Uploading to GitHub
- **3 steps, with links:** make a free account, create an empty repository (don't tick "Add a README"), paste its web address. The technical fields are prefilled and tucked under **Advanced**.
- **No surprise windows:** before your first upload GitCompass tells you a GitHub sign-in window from Git will open, and what to click.
- **Clearer wording:** "Sign in to GitHub" (was "Sign in to GitHub API"). Review requests show a plain "not available in this test version" note instead of asking for a client ID.

Not code-signed yet: on "Windows protected your PC", choose **More info**, then **Run anyway**.
