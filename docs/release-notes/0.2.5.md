# GitCompass 0.2.5 (beta)

## What's new

- **Glossary on hover.** Hold the pointer over any text that mentions a Git word (commit, stage, branch, merge, push, pull, fetch, remote, clone, stash, diff, conflict, repository, HEAD) to see a one-line everyday definition and the name of the offline lesson that covers it. Screen readers get the same definitions as help text.

Requirements, checksum steps and known limitations are unchanged from [0.2.0](0.2.0.md) and [0.2.2](0.2.2.md).
