# GitCompass 0.2.7

## What's new: plain words, help on F1, links to the official docs

- **Plain button names.** For example *Confirm and run this step*, *Preview saving this version (commit)* and *Preview your first upload (push)*.
- **Branches and Pull requests pages in everyday words**: *lines of work (branches)* and *review requests (pull requests)*.
- **Press F1 (or the "?" button) for "What do these words mean?"** It works with the keyboard and screen readers. You get a short definition, a button to open the lesson, and a link to the official docs.
- **"Learn more on git-scm.com ↗" links** in word tips, lessons and problem cards. They open in your web browser. The README's *Words you'll see* table links each word too. *Pull request* and *fork* are new words in the list.
- **Lessons rewritten for beginners**, with no unexplained Git jargon.
- **Readable colours**: every text colour in the light, dark and Liquid Glass themes meets WCAG AA (4.5:1). Your Windows accent colour is adjusted automatically when it would be too faint.

Nothing about safety changed: every change is still previewed and needs your OK.

Known limits: the app is not code-signed (Windows SmartScreen: *More info → Run anyway*). GitHub sign-in needs a GitHub App client ID. The PDF manual was not regenerated for this release. Requirements and checksum steps are unchanged from [0.2.0](0.2.0.md).
